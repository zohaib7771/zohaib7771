## About

I build the engines that build the ads.

As a 3D Technical Artist, Tool Maker and Playable Developer at **Mindstorm Studios**, I own the pipeline that turns a creative concept into a shippable playable ad or video ad — end-to-end.

My approach is AI-first. On a typical 8-hour day, ~7.5 hours are AI-orchestrated — Claude for engineering and architecture, ChatGPT for ideation and copy, Gemini for research. The result is shipping velocity that would normally take a 3–4 person team.

## What I work on

- **Playable Engine (proprietary):** a reusable HTML5 framework — one codebase ships to AppLovin, Mintegral, Facebook, Google, Unity Ads, ironSource, Vungle, and Chartboost.
- **WebThree.js Engine (proprietary):** a Three.js / WebGL foundation purpose-built for interactive 3D ad experiences and web products. Integrates with the Playable Engine as a 3D rendering layer.
- **AI-driven ad pipeline:** LLM-orchestrated workflow that takes a concept to a shipping ad with minimal human handoff.
- **Creative production for mobile games & ads:** 3D asset creation, animation, render pipelines, and automated post-production.

## Flagship projects

### Playable Engine *(proprietary)*
Reusable HTML5 playable-ads framework built from scratch. One codebase ships to every major ad network — AppLovin, Mintegral, Facebook, Google Ads, Unity Ads, ironSource, Vungle, Chartboost — with per-network build configs handled automatically. Features a plugin system for custom interactions, an asset pipeline, and multi-variant A/B build support, enabling same-day concept → ad turnaround at Mindstorm Studios.
**Stack:** JavaScript · HTML5 · Canvas · Webpack &nbsp;·&nbsp; **Role:** Creator & lead maintainer

### WebThree.js Engine *(proprietary)*
A Three.js / WebGL engine purpose-built for interactive 3D ad experiences and web products. Abstracts scene setup, physics hooks, mobile-first performance tuning, and integrates with the Playable Engine as a 3D rendering layer. Built from scratch to make high-quality 3D web and ad experiences shippable in days, not weeks.
**Stack:** Three.js · WebGL · JavaScript · TypeScript &nbsp;·&nbsp; **Role:** Creator

### AI-Driven Ad Production Pipeline
LLM-orchestrated workflow combining Claude (engineering & architecture), ChatGPT (ideation & copy), and Gemini (research) — automating ~95% of a traditional 3-person ad-production team's daily work. Shipping velocity equivalent to a 3–4 person team, run by one technical artist + AI.
**Stack:** Claude · ChatGPT · Gemini · Playable Engine · WebThree.js

## Live products & sites

### [MeshGrab](https://meshgrab.com) &nbsp;·&nbsp; meshgrab.com
Desktop downloader for saving 3D models from AI generation platforms (Meshy, Tripo3D) so creators avoid paying per-model credits. Batch-downloads up to 100 models at once across GLB, FBX, and OBJ with textures; handles meshopt decompression and format conversion; integrates with Sketchfab and Blender.
**Stack:** Python · Node.js · Windows desktop

### [Digital Global Studio](https://digitalglobalstudio.netlify.app) &nbsp;·&nbsp; digitalglobalstudio.netlify.app
Service landing page for my playable-ads and video-ads production — puzzle, casual, match, merge and tycoon genres, 3–5 day turnaround, built with the Playable Engine on Cocos Creator and Unity.
**Stack:** HTML / CSS / JS static site · Netlify
